## 🧭 О проекте

**GeraKStore** — каталог приложений и связанных материалов для экосистемы GeraK. Репозиторий содержит веб-страницу каталога, сведения о приложениях, значки и файлы манифестов, используемые совместимыми инструментами установки.

## ✨ Что входит в репозиторий

- 📱 **Каталог приложений** — список приложений и их метаданные.
- 🔎 **Поиск и навигация** — интерфейс для просмотра каталога.
- 🖼️ **Значки приложений** — изображения для карточек каталога.
- 📄 **Манифесты** — файлы `plist`, связанные с доступными приложениями.
- 🔄 **Данные каталога** — файл `repo.json`, используемый совместимыми клиентами.

Совместимость и доступность конкретного приложения зависят от его манифеста, источника загрузки и используемого установщика.

## 🧱 Структура

| Путь | Назначение |
|---|---|
| `index.html` | Главная страница каталога |
| `repo.json` | Данные репозитория приложений |
| `icons/` | Значки приложений |
| `plist/` | Манифесты приложений |
| `ipa/` | Каталог для файлов IPA; фактическое содержимое зависит от состояния репозитория |
| `.github/ISSUE_TEMPLATE/` | Формы предложений, запросов и сообщений об ошибках |
| `assets/` | Дополнительные визуальные материалы |

Не переименовывайте и не перемещайте файлы данных, манифесты и значки без проверки ссылок в `repo.json` и связанных интерфейсах. Изменение структуры может нарушить отображение или загрузку приложений.
